Core Architecture

Enterprise Infrastructure Capabilities

Hybrid Intelligence Pipeline

Executes sub-millisecond deterministic regex and NLP sequence matching locally. Automatically routes unmatched vectors to the embedded Google Gemini LLM API.

WSGI Concurrency

Powered by the Waitress production server, handling thousands of concurrent webhook requests asynchronously without memory degradation.

Zero-Dependency Binaries

Compiled natively via PyInstaller, wrapping Flask, SQLite drivers, and AI modules into a single execution payload requiring no runtime installations.

Containerized Tenant Nodes

Provisions strictly isolated workspaces per tenant. Each node operates on dynamic port mapping with independent SQLite DAO storage instances.

Stateful Lifecycle Auditing

Synchronous cron-based telemetry tracking instance TTL (Time To Live). Executes automatic SIGTERM and namespace deletion upon expiry.

Multi-Layer RBAC

Implements strict Role-Based Access Control distinguishing Root Admin privileges from standard Tenant Operators for complete financial and process orchestration.
